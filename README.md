# Cosmetics Store

Welcome to the **Cosmetics Store** project! This is a full-stack web application that allows users to browse and purchase cosmetics online. It features a user-friendly interface, secure authentication, a shopping cart system, and an admin panel for managing products and orders.

## Key Features:

- **User Authentication**: Secure login and registration for users.
- **Product Catalog**: Browse through a variety of cosmetics products with detailed descriptions.
- **Shopping Cart**: Add products to your shopping cart and proceed to checkout.
- **Admin Panel**: Admin can add, update, and remove products from the catalog and manage orders.
- **Order Management**: Users can track their orders and view past purchase history.

## Technologies Used

### Frontend:
- **React.js** 

### Backend:
- **Node.js** with **Express.js** 
- **MySQL** (for storing products, user data, orders, etc.)
- **JWT** (for user authentication)

### Installation

1. Clone the repository:
   ```bash
   https://github.com/ayalagellis/Full-stack-project-7.git

2. Install frontend dependencies:
    ```bash
    cd Client
    npm install

3. Install backend dependencies:
    ```bash
    cd Server
    npm install
    
4. Configure environment variables:
Create a .env file in the backend directory with your MySQL credentials.
    
### Usage

1. Start the backend server:
   ```bash
   cd Server
   npm run dev

2. Start the frontend development server:
   ```bash
   cd Client
   npm run dev

3. The address to access the application will be displayed in your terminal once you run the application. Look for a line like:
Local: http://localhost:5173/ (the port may vary).
